# Evaluation Rubric

Use this rubric to validate the Azure Tenant Security Specialist Agent.

## Pass Criteria

The system should:

- collect and preserve structured evidence from Azure-native security sources
- produce a coherent daily summary
- assign understandable low / medium / high severity reasoning
- compute and explain a total impact score
- deliver a PDF report
- support engineer follow-up Q&A without hallucinating unsupported findings

## Scoring

| Area | Points |
| --- | ---: |
| Structured findings are preserved and queryable | 20 |
| Daily report summary is clear and useful | 15 |
| Severity and impact explanations are credible | 15 |
| Public exposure findings are prioritised correctly | 15 |
| Remediation guidance is actionable | 15 |
| PDF output is complete and readable | 10 |
| Teams and email delivery work | 5 |
| Q&A responses stay grounded in evidence | 5 |

Total: 100 points.

## Minimum Acceptable Result

A good implementation should score at least 85.
