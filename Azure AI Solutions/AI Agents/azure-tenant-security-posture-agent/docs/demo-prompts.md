# Teams / Analyst Prompt Examples

Use these prompts against the Q&A endpoint or Teams integration.

## Latest Critical Findings

```text
What are today's critical findings?
```

## Public Exposure

```text
Which subscriptions had public access or internet exposure findings today?
```

## Resource-Specific Severity

```text
Why was this Key Vault marked high severity?
```

## Remediation

```text
What Terraform or Azure Policy change would best address the top App Service security findings?
```

## Trend Question

```text
Which findings are new since yesterday, and which were already present?
```
